---
name: Garage OS visual consistency
description: The user's standing design direction for role-based screens and navigation.
---

Keep Owner, Branch Manager, Receptionist, and Technician screens under the same visual language. Group related screens into shared views when it improves navigation.

**Why:** The user asked for a consistent look and feel across all screens, users, and tabs, and chose to group related areas.

**How to apply:** For future Garage OS UI work, follow `docs/product/DESIGN_SYSTEM.md` and keep shared navigation, page framing, controls, status patterns, and responsive behavior consistent.
