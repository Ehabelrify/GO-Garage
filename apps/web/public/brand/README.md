# GO Stores brand assets (CONCEPT)

These files are a concept built by Codex from social-media references. They are NOT approved artwork.
Maher (brand owner) must approve the identity; his original vector files then replace these as a drop-in
(same file names, same viewBox ratios if possible). No code changes are needed for a swap.

Files: `logo-primary.svg|png` (light surfaces, login, print), `logo-reversed.svg` (graphite sidebar), `mark-primary.svg|png`
(rail, mobile top bar), `app-icon.svg|png` (apple-touch-icon), `favicon.svg|png`. `../logo.svg` and `../favicon.svg` are copies of the primary logo and favicon.
Source: `docs/product/go-stores-brand-identity-2026-11-22/`. Never retype the wordmark in a font.

Fonts: IBM Plex Sans and IBM Plex Sans Arabic WOFF2 (latin and arabic subsets, 400/500/600/700) are in `../fonts/` (SIL OFL, `OFL.txt`).
Downloaded from jsDelivr's fontsource mirror (files only, no npm dependency). IBM Plex Sans Arabic Latin glyphs are not shipped;
Latin text uses IBM Plex Sans.
