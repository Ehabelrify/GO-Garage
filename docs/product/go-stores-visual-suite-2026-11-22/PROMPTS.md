# Visual generation prompt set

All boards were produced with the built-in image-generation tool. The current application screenshots were used as structural references and the approved brand board was used as the visual reference. Images are exploratory raster concepts, not production UI assets.

## Global prompt

Create a high-fidelity GO STORES automotive operations application using the existing product's information architecture. Use graphite `#17191D` and warm white `#F6F4EF` as dominant surfaces, performance red `#C82127` for the customer-facing brand and sparing primary emphasis, yellow-gold `#F3B61F` for controlled attention/premium/selection emphasis, and brushed silver `#B9BEC4` for technical borders. Keep brand colors separate from semantic danger, warning, success and information states. Use compact, bilingual-capable enterprise UI, structured tables/lists, minimal shadows, small radii, accessible contrast and restrained metallic detail. The exact master-brand text is “GO STORES”. Exclude the transformer/robot, mascot, crown from the everyday identity, storefront imagery, decorative cars/people, marketing-poster composition, glassmorphism, excessive gradients, fake completion and invented business policy.

## Board prompts

1. **Brand system:** primary/compact/dark/light logo treatments, palette with hex values, English/Arabic typography direction, sidebar/dashboard component examples, buttons/status accents and a separate premium gold badge.
2. **Owner overview:** preserve the current role-based sidebar, top bar, search, branch selector, metric tiles, attention table and mobile navigation; apply the brand system without changing workflows.
3. **Reception command center:** six-number central inbox, source channel, ownership/SLA, conversation, internal note versus reply, customer/vehicle context, capacity-aware booking drawer, today drop-offs/pickups and provider-disconnected simulation label.
4. **Workshop:** branch job board with real stages, risk and assignment prerequisites; technician mobile “My cars today”, focused job, evidence/checklist, next actions; sequential intake and QC pass/fail/rework.
5. **Customer/Vehicle 360:** searchable customer list, linked vehicles, purchases, bookings/workshop, quotes, warranties, benefits, transport, invoices, conversations, special requests, connected activity history and reversible owner archive/audit.
6. **Commercial lifecycle:** versioned catalogue package and quote, acceptance evidence, print action, reservation for later installation without workshop capacity, promotion/referral/multi-car qualification and auditable benefit redemption; visibly label sample/unconfirmed values.
7. **Warranty:** contextual coverage workspace, explicit fixed/lifetime kind, issued terms history, aftercare entitlements, claims/invoices/QR/history tabs, issuance prerequisites and privacy-safe public verification; never convert lifetime into arbitrary months.
8. **Finance/reporting:** separately define quoted value, collections, balance, recognized revenue, costs, overhead and profit; purposeful trend, branch comparison, source drill-down, reversals and sample-definition attestation; label inventory/purchasing as future and full ERP as out of scope.
9. **Settings/readiness/roadmap:** invite-only staff access, role/branch/capability scope, auditable business settings, on-hold policies, migrations/provider/purge/backup/visual/security/publication gates, 60-issue snapshot, current/operational-completion/future phases and unresolved owner decisions.
