# GO Stores identity usage guide

## Brand hierarchy

1. **GO Stores master logo:** everyday customer-facing and application identity.
2. **Compact GO turbine mark:** app icon, small navigation, avatar, social profile and favicon contexts.
3. **Premium lockup:** limited campaign/package use. It must not replace the master logo in the application shell.
4. **Transformer character:** optional fictional social-content device only. It is excluded from the logo, application icon, navigation and permanent product identity.

## Color hierarchy

Graphite and warm white create the environment. Red supplies recognition. Yellow-gold supplies a small premium/attention signal. Silver provides technical support.

Use only one saturated leader in a component:

- Red button with neutral surroundings.
- Gold selection or focus detail with graphite text.
- Green success state with a text label.
- Red critical state only when the meaning is truly critical, not merely because red is the brand color.

## Interface examples

- Sidebar: graphite, reversed logo, white labels, selected row in warm white, slim red leading edge.
- Header: white or warm-white surface, primary logo only when the sidebar is absent.
- Metric tiles: neutral surfaces; reserve red for overdue/critical and gold for attention/in-progress.
- Forms: neutral borders; gold focus should not be confused with validation warning.
- Documents: primary logo on white; monochrome dark when color printing is unavailable.
- Premium offer: graphite field, gold GO detail, warm-white wordmark; keep regular content outside the premium lockup.

## Prohibited combinations

- White text on yellow-gold.
- Large red background directly beside a large gold background.
- Gold body text on warm white.
- Red success states or gold destructive actions.
- Metallic gradients in routine UI components.
- Crown on navigation, loading screens or favicon.
- Transformer/robot incorporated into the permanent mark.

## Asset selection

- Website/application light surface: `assets/logo-primary.svg`.
- Dark sidebar: `assets/logo-reversed.svg`.
- Small square application placement: `assets/app-icon.svg`.
- Browser icon: `assets/favicon.svg`.
- Single-color engraving/stamp: monochrome SVG.
- Presentation/package marked premium: `assets/premium-lockup.svg` only with owner approval.
